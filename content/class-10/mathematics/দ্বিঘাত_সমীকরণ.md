# একচলবিশিষ্ট দ্বিঘাত সমীকরণ

## ১. দ্বিঘাত সমীকরণের সাধারণ রূপ
একটি চলরাশিযুক্ত দ্বিঘাত সমীকরণের প্রমিত রূপ হলো:
$$ax^2 + bx + c = 0 \quad (a \neq 0)$$

এখানে $a, b, c$ বাস্তব সংখ্যা।

## ২. শ্রীধর আচার্যের সূত্র
দ্বিঘাত সমীকরণের বীজ দুটি নির্ণয়ের সাধারণ সূত্র:

```text
x = (-b ± √(b² - 4ac)) / (2a)
```

## ৩. নিরূপক (Discriminant) ও বীজের প্রকৃতি
$D = b^2 - 4ac$ রাশিটিকে সমীকরণের নিরূপক বলা হয়।

| নিরূপকের মান ($D$) | বীজের প্রকৃতি |
| :--- | :--- |
| $D > 0$ | বীজ দুটি বাস্তব এবং অসমান |
| $D = 0$ | বীজ দুটি বাস্তব এবং সমান ($x = -b / 2a$) |
| $D < 0$ | বাস্তব কোনো বীজ নেই (অবাস্তব/কাল্পনিক) |

> [!TIP]
> যদি $a$ ও $c$ এর চিহ্ন বিপরীত হয় ($ac < 0$), তবে $D = b^2 - 4ac > 0$ সর্বদা বাস্তব বীজ প্রদান করবে।
