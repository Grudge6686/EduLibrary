# বীজগণিতীয় সূত্রাবলী ও প্রয়োগ

## ১. ভূমিকা
বীজগণিত হলো গণিতের এমন একটি গুরুত্বপূর্ণ শাখা যেখানে সংখ্যা এবং অজ্ঞাত রাশির সম্পর্ক প্রতীক চিহ্নের সাহায্যে প্রকাশ করা হয়। এই পাঠে আমরা মৌলিক বীজগণিতীয় অভেদাবলী সম্পর্কে বিশদ আলোচনা করব।

## ২. প্রমিত অভেদাবলী (Standard Identities)

নিচের সূত্রগুলি সর্বদাই সত্য এবং যেকোনো মানের জন্য প্রযোজ্য:

```text
সূত্র ১: (a + b)² = a² + 2ab + b²
সূত্র ২: (a - b)² = a² - 2ab + b²
সূত্র ৩: a² - b² = (a + b)(a - b)
সূত্র ৪: (a + b + c)² = a² + b² + c² + 2(ab + bc + ca)
```

> [!IMPORTANT]
> মনে রাখবেন, সমীকরণ (Equation) এবং অভেদের (Identity) মধ্যে পার্থক্য রয়েছে। অভেদ চলকের যেকোনো বাস্তব মানের জন্য সিদ্ধ হয়।

## ৩. গুরুত্বপূর্ণ অনুসিদ্ধান্তসমূহ

| মূল সূত্র | অনুসিদ্ধান্ত রূপ ১ | অনুসিদ্ধান্ত রূপ ২ |
| :--- | :--- | :--- |
| $(a + b)^2$ | $a^2 + b^2 = (a+b)^2 - 2ab$ | $(a+b)^2 = (a-b)^2 + 4ab$ |
| $(a - b)^2$ | $a^2 + b^2 = (a-b)^2 + 2ab$ | $(a-b)^2 = (a+b)^2 - 4ab$ |
| $4ab$ | $4ab = (a+b)^2 - (a-b)^2$ | $ab = ((a+b)/2)^2 - ((a-b)/2)^2$ |

## ৪. সমাধানকৃত উদাহরণ

### উদাহরণ ১:
যদি $x + \frac{1}{x} = 5$ হয়, তবে $x^2 + \frac{1}{x^2}$ এর মান নির্ণয় করো।

**সমাধান:**
```text
x² + (1/x)² = (x + 1/x)² - 2 · x · (1/x)
            = 5² - 2
            = 25 - 2
            = 23
```

> [!TIP]
> পরীক্ষার খাতায় সমাধানের প্রতিটি ধাপে যথাযথ সূত্রের উল্লেখ রাখা বাঞ্ছনীয়।
