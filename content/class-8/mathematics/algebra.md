# Algebraic Expressions & Identities

## 1. Introduction
Algebra is a branch of mathematics dealing with symbols and the rules for manipulating those symbols. In elementary algebra, these symbols (today written as Latin and Greek letters) represent quantities without fixed values, known as variables.

## 2. Core Identities
Standard algebraic identities play a central role in simplifying polynomial products:

```text
Identity I:   (a + b)² = a² + 2ab + b²
Identity II:  (a - b)² = a² - 2ab + b²
Identity III: (a + b)(a - b) = a² - b²
Identity IV:  (x + a)(x + b) = x² + (a + b)x + ab
```

> [!NOTE]
> An identity is an equality which is true for all values of the variables in the equality.

## 3. Operations & Standard Formulas

| Operation | Expression Form | Expansion Result |
| :--- | :--- | :--- |
| Square of Binomial Sum | $(a + b)^2$ | $a^2 + 2ab + b^2$ |
| Square of Binomial Difference | $(a - b)^2$ | $a^2 - 2ab + b^2$ |
| Difference of Squares | $(a + b)(a - b)$ | $a^2 - b^2$ |
| Product with Shared Term | $(x + a)(x + b)$ | $x^2 + (a + b)x + ab$ |

## 4. Solved Examples

### Example 1: Expand $(2x + 3y)^2$
Applying Identity I where $a = 2x$ and $b = 3y$:
```text
(2x + 3y)² = (2x)² + 2(2x)(3y) + (3y)²
           = 4x² + 12xy + 9y²
```

### Example 2: Compute $103 \times 97$ without direct multiplication
Notice that:
```text
103 × 97 = (100 + 3)(100 - 3)
         = 100² - 3²
         = 10000 - 9
         = 9991
```

> [!TIP]
> Factorization is the reverse process of expanding algebraic expressions. Always look for common monomial factors first.
